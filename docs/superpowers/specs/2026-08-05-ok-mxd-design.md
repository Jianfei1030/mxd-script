## 1. 背景与目标

将 ok-ww（鸣潮视觉自动化工具，`H:\ok-mxd\data\apps\ok-ww\repo`）的"视觉自动化模式"移植到冒险岛怀旧服（MapleStory Classic)，实现站桩式自动打怪。

**目标游戏环境**（已实测确认）:

- 进程：`Maplestory_Classic.exe`(Unity 引擎，窗口类 `UnityWndClass`，标题 `冒险岛怀旧服`)
- 路径：`H:\冒险岛online\mxdclassic\Maplestory_Classic.exe`
- 分辨率：2560x1440（窗口客户区）
- 反作弊：BlackCipher64.aes(Nexon Game Security）在运行
- 角色：冰雷法师方向，当前 **LV.17** 魔法师（二转前用 Shift 单体技能，二转后换群雷，按键均可配置）；有宠物小白雪人；常组队
- WGC 后台截屏**已实测可用**（窗口被遮挡也能取帧）;PrintWindow 为黑图，不可用
- 小地图（2026-08-05 实测）:**不显示怪物**。红点=其他玩家/装饰，黄点=NPC/玩家，青色圈=传送门
- 快捷栏（已实测可读）:Ins=蓝药×276、Home=红药×15、Shift/Ctrl=技能、Pgup=宠物食品；**回城卷不在栏上**，需用户拖入后配置键位
- 状态栏（已实测）:HP/MP/EXP 固定位置纯色条 + 精确数字文本（如 `HP [342/342]`)
- 怪物受击后头顶显示红血条，可作为辅助信号

**功能范围（MVP)**:

1. 基础打怪循环（站桩式，**YOLO 检测怪物进入攻击区才放技能**;YOLO 模型未就绪前退化为定频空放）
2. 自动喝药（HP/MP 低于阈值，含药水耗尽保护）
3. 自动补 Buff（魔法盾等）
4. 自动拾取：**默认关闭**，依靠宠物拾取（走位拾取有掉下平台风险，作为可开关的实验项）

## 2. 方案

完整移植 ok-ww 仓库骨架，保留 `ok/` 框架与 GUI，重写游戏层。复用启动器自带 Python 3.12 环境（`H:\ok-mxd\data\apps\ok-ww\python\python.exe`)，零环境搭建。

**账号风险声明**（与 ok-ww 一致）：本工具不读内存、不注入、不碰封包，仅截屏+模拟输入，规避了一大类检测面；但反作弊仍可观察进程、窗口句柄与输入行为特征，**使用即有封号风险，后果自负**。

## 4. 核心检测策略

| 状态 | 方法 | 说明 |
|---|---|---|
| HP/MP/EXP | 状态栏 ROI 颜色占比（主）+ OCR 数字校验（每 5s 低频） | OCR 文本格式 `HP [342/342]`，直接给精确值 |
| 药水余量 | 快捷栏对应格子数量 OCR(276/15 字样可读） | 耗尽 → 停任务+通知 |
| Buff | buff 图标区模板匹配 | 需截魔法盾等图标素材 |
| 怪物 | YOLOv8 ONNX(v3 起并入 MVP:检测框进入攻击区才放技能;模型未就绪前定频空放) | 每种怪一个类别,可泛化动画/朝向/换图;框架有同款管线(ok-ww 声骸检测);训练数据自截自标 |
| 兜底异常 | 帧差分（画面长时间无变化）、EXP 数值长时间不涨 | 覆盖卡死/被清图/掉线 |

**ROI 定位原则**（修订）：冒险岛 UI 是可拖动浮动面板（小地图有 -/+ 缩放与折叠，状态栏/快捷栏/聊天框均可拖）。因此：
- 所有 ROI 不用裸比例坐标，改为**模板匹配面板锚点 → 相对偏移取 ROI**
- M0 增加实测：同一面板在两个分辨率下是"固定像素"还是"随分辨率缩放"
- 写明运行约束：**挂机期间不得拖动/缩放/折叠任何 UI 面板**

## 5. 主循环(MapleFarmTask,触发任务)

```
取帧(next_frame)
1. 读 HP%/MP%(颜色占比;每 5s 用 OCR 数字校验一次,偏差大则以 OCR 为准)
2. HP < 喝血阈值(默认可配,考虑法师脆皮建议 70%)→ 按血药键
   MP < 35% → 按蓝药键
3. 保命(尽力而为,不保证存活——0.3s 轮询+卷轴吟唱可能来不及):
   HP < 25% → 若已配置回城卷键:按回城卷 → 停任务+通知
              若未配置:直接停任务+通知(接受死亡风险)
4. 药水保护:快捷栏数量 OCR(低频,每 30s)
   血/蓝药耗尽 → 停任务+通知
   连续 5 次喝血后 HP 仍 < 阈值 → 停任务+通知(打不过我方的怪)
5. Buff 巡检(每 10s)→ 缺哪个按哪个
6. 攻击(两种模式,可配):
   检测模式(YOLO 就绪后默认):怪物检测框中心进入攻击区(以画面中心为锚的可配区域)
   → 放攻击技能;无怪 → 停手等待(省蓝)
   定频模式(YOLO 未就绪的降级):按固定节拍放攻击技能键(节拍可配,默认 1.5s)
   蓝耗均由第 2 步兜住
7. 拾取:默认关闭(靠宠物)。若手动开启:每 30s 小步左右移动+拾取键×3
   (有掉下平台风险,实验性功能)
8. 兜底(每轮):
   画面帧差分静止 > 60s → 疑似卡死/掉线 → 停任务+通知
   EXP 数值 > 10 分钟不涨 → 疑似无效挂机 → 停任务+通知
```

## 6. 输入与截屏

- 截屏:`['WGC', 'BitBlt_RenderFull']`(WGC 已实测后台可用）
- 输入：首选 `PostMessageInteraction`（后台生效）。
- **决策规则（显式）**:M0 实测 PostMessage 无效 → 降级 `PyDirectInteraction`（前台 SendInput)→ **产品定位从"后台无人值守"退为"前台独占挂机"**：窗口须前台、会抢键鼠、§5-7 走位拾取禁用、用户不能同时用电脑。此后果在 M0 结束时向用户明示后再继续 M1。
- 按键映射用框架 key_config_option;攻击/血药/蓝药/buff/拾取均可配;**回城卷键为可选配置项**——留空表示未配置，此时低血策略退化为"直接停任务+通知（接受死亡风险）"（见 §5-3)，不阻塞其他任何功能。

## 7. 异常处理与安全

| 场景 | 策略 |
|---|---|
| **未知模态弹窗**（验证码/防沉迷/公告/任何覆盖游戏画面的对话框） | 停任务+通知（最重要兜底，覆盖一切未预料情况） |
| 掉线/回登录界面 | 停任务+通知 |
| 画面静止 > 60s / EXP 10 分钟不涨 | 停任务+通知 |
| HP < 25% | 回城卷（若已配键）→ 停任务+通知；**尽力而为，仍可能死亡** |
| 血/蓝药耗尽；连续喝药无效 | 停任务+通知 |
| 死亡（墓碑/复活界面模板） | 停任务+通知，不自动点复活 |
| PostMessage 失效 | 按 §6 决策规则降级 |
| 紧急停止 | 框架自带全局热键（F9) |
| 分辨率变更 | 锚点模板重定位；不支持的比例直接报错提示（supported_resolution 放宽，不照抄 16:9) |
| 账号风险 | 见 §2 风险声明 |

**M0 技术验证（全部过了才进 M1)**
1. WGC 截屏——判据：窗口被完全遮挡时取帧清晰可 OCR。✅ 已通过（2026-08-05)
2. 小地图语义——判据（写死）：安静频道普通练级图，站桩 30s 录屏存帧：①清怪后红点消失且重生后回来=怪，否则=玩家/NPC;②点移动轨迹判别；③队友进图新增点的颜色；④检查游戏设置有无"小地图显示怪物"开关。❌ 已证伪（2026-08-05：红点=玩家/装饰，怀旧服小地图不画怪）。攻击主路径已改为定频空放，本项结论仅影响 minimap.py 只保留"无变化兜底"职责
3. PostMessage 按键——判据：游戏窗口无焦点时，发送按键后游戏产生可见响应（如快捷栏药水数量减少/UI 面板开合）,10 次全中为通过。❌ 已证伪（2026-08-05 实测：PostMessage / ForegroundPostMessage / 管理员 PostMessage 均被 BlackCipher 拦截，error 5 或静默忽略；最终档位 PyDirect + 管理员运行，窗口必须前台）。产品定位从"后台无人值守"退为"前台独占挂机"
4. 血蓝条 ROI——判据：10 组采样帧，颜色占比读数与画面 `[x/y]` 数字误差 < 5%。✅ 已通过（2026-08-05）
5. UI 缩放行为——判据：记录同一面板在两个分辨率下的像素尺寸，明确"固定像素/比例缩放"，据此定 ROI 方案。✅ 已通过（2026-08-05：UI 随分辨率比例缩放，如 HP 条 200px@1440p vs ~110px@1080p，采用比例 ROI + 运行时帧尺寸守卫）
