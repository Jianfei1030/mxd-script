# 丢锚完全丢失治理 —— 反向外推防护 / 外推封顶 / 拒绝拍观测 / 唯一框接管（2026-08-10）

承接 2026-08-09 的 YOLO 融合阶梯。那次上线后丢锚时长大幅收敛，但「完全丢失」
（三级通道全部失效、只能靠慢扫找回、拖 2.6~10s+）仍反复出现。本文档针对
2026-08-09 晚与 2026-08-10 晚两段日志的逐拍解剖结论做四条修法。

## 1. 现状与根因

### 1.1 相关现状（事实来源：src/task/MapleFarmTask.py、src/task/farm_logic.py)

锚点阶梯：模板分片(±240/±80 窗) → OCR 快窗(±240/±80) → 身份复验慢扫 →
YOLO 关联级(门 ±240/±120，`player_gate_size` 按 dt 从 110/70 线性放到封顶，
**永不超封顶**) → 慢扫(节流 2s + 丢锚立即重扫) → cached(寻怪中按外推 x) →
fallback(屏幕中心 x + 最后已知 y)。

外推（`_extrapolated_anchor_x`,MapleFarmTask.py:336-354）：锚点年龄
0.5s~保鲜(10s) 内，实测速度新鲜(≤2s)且非零时**直接用学习 vx，不看寻怪方向**;
否则用配置速度 × 寻怪方向；结果钳在 [0, 2560]。学习 vx 对 yolo 拍伪锚点同样
低通学习(`_update_anchor` 对全部通道统一调用)。

### 1.2 实测证据(2026-08-09/10 两段日志)

**根因一：反向外推逃逸(源头)。** 丢失瞬间学到的 vx 与寻怪方向反向时，外推
把 pred 往反方向推，真实角色越走越远，1s 内出 ±240 的门；此后模板窗/快窗/
YOLO 门三级全拴在逃逸的 pred 上，只剩慢扫能找回。

- 08-09 21:53:击退漂移被学成 +75px/s(右)，寻怪 left,pred 1948→2088 右爬，
  真人左跑，恢复拍 body_x=440 与 pred 差 1500px。
- 08-10 19:56:48 **钳位铁证**:yolo 追踪 x=2260 → 角色左转 + 单拍漏检 →
  cached 拍 x=2560(钳在帧右缘)而 寻怪=left,pred 钉死 12s 至 fallback。
- 08-10 19:46:03-04:cached 拍 x 1319→1423 持续右爬而 寻怪=left，随后
  region 在 x=1151 找回真人(pred 逃在真人右边 272px)。

**根因二：丢失期外推 ↔ 寻怪决策振荡反馈(08-10 新发现)。** 丢锚后外推位移
随年龄涨到 ±2500px(250px/s × 10s 保鲜)，攻击区跟着 pred 瞬移 → 怪在区内
进进出出 → 寻怪方向每拍翻转 → 外推翻到另一个钳位极值 → 循环。门中心每拍
跳 ±1250px,YOLO 即使一直看见角色，也只有部分拍次门恰好罩住它。

- 08-10 21:18:20-30 cached:x = 1454→1633→916→713→1454→246→**2560**→1454
  →**0**→1454→**0**,1454 = 锚点原位(寻怪=None 的拍),0/2560 = 双向钳位。

**根因三：门封顶且无升级路径(结构)。** `player_gate_size` 封顶 ±240/±120 是
刻意设计(docstring:门再放大=谁都能认成自己，交给慢扫验名)。但慢扫要名字牌
OCR 可读，怪堆/换层时恰恰读不出——恢复路径单一且恰在故障场景失效。
另外换层(层高差实测 240-300px)瞬间，快窗 ±80、YOLO 门 ±120 的纵向也全灭。

**观测缺口(排查被它挡过两次路)。** `_last_yolo_info` 只在 YOLO **接受**拍记，
拒绝拍/未到达拍日志全写 `yolo候选=-`,无法区分「没检出」「检出被门拒」
「多候选身份过期拒裁」。

## 2. 方案选型(含被否项)

**选定:四条小修，全部落在既有阶梯与既有函数内，不改架构。**

被否项：
- **门随丢锚年龄无限放宽** —— 2026-08-09 spec 已明确拒绝(门再放大=谁都能
  认成自己)。修法 4 用「全屏唯一框」唯一性判据替代宽门，语义不同。
- **反向时不学习 vx(只改学习点)** —— 已学进去的反向 vx 还能在 2s 窗口内
  继续毒化外推，逃逸 1s 内就出门，治不好。必须改使用点(修法 1)。
- **丢失期禁外推(回 2026-08-06 前行为)** —— 外推是「怪堆里一直寻怪不攻击」
  的主解，不能因噎废食;封顶(修法 2)保留近期外推、只砍掉远期失控段。

## 3. 设计

### 3.1 修法 1:vx 反向防护(使用点)

`_extrapolated_anchor_x` 取学习 vx 前先比符号:`vx` 与 `_seek_dir` 反向时
丢弃学习值，落到既有的「配置速度 × 寻怪方向」分支。学习点
(`anchor_vx_update`)不动:击退残余会在下一次真实行走观测时被低通自然替换。

判定抽成 farm_logic 纯函数:

```python
def extrapolate_vx(learned_vx, seek_dir, cfg_speed):
    """外推速度:学习值与寻怪方向同向才用,反向/无学习值用配置速度 × 方向。"""
```

边界:`learned_vx == 0`(从未学到) → 配置速度;`_seek_dir is None` 时
`_extrapolated_anchor_x` 既有提前返回不受影响。

### 3.2 修法 2:外推位移封顶

`_extrapolated_anchor_x` 返回值再加一道位移钳:

```python
ANCHOR_EXTRAPOLATE_MAX_DX = 500   # 外推位移上限(px) ≈ 2s 行走量
x = anchor[0] + clamp(vx * age, -MAX_DX, +MAX_DX)
```

拆掉振荡回路:pred 不再随年龄无限远离，攻击区稳定 → 寻怪方向稳定 →
门中心稳定，YOLO 关联与修法 4 才有稳定工作环境。500px 的依据:寻怪中
2s 内名字牌大概率重新可读(模板/快窗 10Hz 在咬),2s 行走量足够跟上真人;
真超过 2s 的丢失本来就该由慢扫/修法 4 接管，而不是靠外推猜。帧边界
[0, 2560] 钳位保留。

### 3.3 修法 3:YOLO 拒绝拍补观测

`_last_yolo_info` 改为 YOLO 级**执行即记**(不止接受拍),元素扩为
(门内候选数, 关联距 or None, 全屏 player 框数):

- 接受拍:同现状 + 全屏数;
- 拒绝拍(0 候选 / 多候选身份过期):记 (len(gated), None, len(players));
- 全屏 0 框(推理了但没检出 player):记 (0, None, 0)——`_resolve_anchor`
  签名默认值 `players=()` 改 `players=None`,None=定频/旧调用(本拍无推理)
  保持短路不记,[] 正常走完 YOLO 级。「没检出 vs 未到达」必须分得开;
- 未到达(模板/快窗命中、开关关、players=None 无推理):保持 None。

`decision_log_line` 行尾追加可选字段 `yolo全屏=N`(默认 None → `-`)。
追加在行尾不动既有字段:analyze 脚本前缀匹配、绑定测试用关键字参数构造,
全部不受影响。从此可区分:`-/-`=未到达;`候选=0 全屏=1`=检出被门拒;
`候选=0 全屏=0`=真没检出。

### 3.4 修法 4:丢锚唯一框接管(阶梯末级安全网)

YOLO 级内、常规门裁决失败后再走一级:

```
锚点年龄 > LOST_UNIQUE_MIN_AGE(1.0s)
且 全屏恰好 1 个 player 框
且 该框换算后的 y 落在 pred_y ± LOST_UNIQUE_GATE_Y(300)
→ 直接接受,不看横向门、不看身份保鲜
```

- **横向完全不看门**:pred 已逃逸,横向先验已死;唯一性就是判据(单人挂机
  全屏 1 框几乎恒是自己,与 `select_player_box` 「门内恰 1 个不看身份」同理,
  只是范围扩到全屏)。
- **纵向保留 ±300**:外推只推 x 不推 y,y 先验丢锚再久也活着;±300 按实测
  层高差 240-300 定,换层逃逸接得住,隔层路人挡得住。
- **身份仍过期**:接受只走 `_update_anchor`,不刷 `_last_identity_hit` →
  复验慢扫每 3s 照跑,认错路人会被名字牌校准循环纠正,误认是暂时的。
- **冷启动不进**(`_anchor is None`),由外层既有结构保证;**多框拒裁**,
  多人图行为不变(宁可慢扫不认错)。

判定抽成 farm_logic 纯函数(与 `select_player_box` 并列):

```python
def select_lost_unique_box(players, pred_y, anchor_age,
                           min_age=1.0, gate_y=300):
    """丢锚超 min_age 且全屏唯一 player 框且同层 → 直接接管;否则 None。"""
```

新配置键:`丢锚唯一框接管开关`(默认 True——复验慢扫兜底存在,误认暂时,
完全丢失是功能全停)。

### 3.5 可观测性验收(修完后 logs 里应看到)

- `src=cached` 拍不再出现 `body_x=0/2560` 与寻怪方向矛盾的钳位签名;
- 相邻 cached 拍 body_x 跳变 ≤ 1000px(封顶 ±500 + 寻怪翻转的最坏摆幅
  2×500,振荡从 ±2500 收敛到有界);
- `yolo候选=0 yolo全屏=1` 的拍可被明确读出(检出被拒 vs 没检出)。

## 5. 风险与回退

- 修法 4 误认风险:路人独自同屏且我方框恰好未检出 → 锚点跟路人走。上界 =
  名字牌下次可读 + 复验间隔(3s 级),且攻击区跟错人期间打怪逻辑照常
  (怪是 YOLO 检的,与锚点身份无关),代价是攻击区位置错,不会打错人。
  回退:配置开关关掉即回滚。
- 修法 4 已知副作用(接受):接管瞬移会被 `anchor_vx_update` 评估——年龄
  >2s 被 dt 门挡、换层(|dy|≥30)被平台门挡,但丢锚 1.0~2.0s 且同层的横向
  逃逸(正是主场景)两道门都拦不住,dx/dt ≤ 600 就会被低通学进去
  (例:age 1.5s、横向 600px → 学到 280px/s)。若恰与寻怪同向,修法 1 的
  反向防护拦不住;影响由修法 2 的 ±500 封顶兜住(外推最多偏 500px,下一
  真实观测即被低通汰换)。测试双锁定:age=3s 换层剧本断言不学(0.0),
  age=1.5s 同层剧本断言在学(280)——锁「知道它学不学、学多少」。
  「不改学习点」的前提因此修订为:不为它加过滤,但知晓并兜底新的跳变来源。
- 修法 2 外推封顶偏紧(500px) → 丢失期攻击区跟不上快走真人。可接受:
  封顶内 YOLO/唯一框接管环境更稳,找回概率上升;实测不够再调。
- 修法 1 极边缘:寻怪方向刚翻转、学习 vx 还是旧方向 → 退回配置速度,
  方向一致,无副作用。

## 6. 测试

farm_logic 单测(test_farm_logic.py):
- `extrapolate_vx`:同向用学习值 / 反向用配置速度 / 零值用配置速度;
- 外推封顶:age 大到 vx*age 超 ±500 时钳在 ±500;帧边界钳位仍生效;
- `select_lost_unique_box`:年龄不足拒 / 多框拒 / 隔层(|dy|>300)拒 /
  唯一同层收 / 边界压线(年龄恰 1.0、|dy| 恰 300)语义;
- `decision_log_line` 新字段:默认 None 输出 `-`,给值输出数字,旧参数
  构造的样本行逐字不变(既有绑定测试不改即绿)。

任务层离线测试(test_farm_task_offline.py,沿用既有假帧/假 OCR 惯例):
- 反向逃逸剧本:yolo 追踪→转向→漏检,cached 拍 pred 不再反向逃离;
- 帧边界复合:锚点 x=100 寻怪 left → dx 钳 -500 后再钳到 0,不出负坐标;
- 振荡剧本:丢锚 + 寻怪方向交替,相邻 cached 拍 |Δbody_x| ≤ 1000
  (=2×500 封顶摆幅,与 §3.5 口径一致);
- 唯一框接管:丢锚 2s + 全屏 1 框 → src=yolo 一拍接管;多框 → 不接管;
  接管拍不刷 `_last_identity_hit`(复验慢扫兜底的根基,必须断言)。

## 7. 不做什么

- 不改 `anchor_vx_update` 学习点(击退残余由低通自然汰换;接管瞬移的
  已知学习由封顶兜底,见 §5,不加过滤);
- 不放宽 `player_gate_size` 封顶(2026-08-09 spec 的明确决策);
- 不动模板分片匹配、身份复验慢扫、丢锚立即重扫的既有行为;
- 多人图(全屏 ≥2 框)不做任何接管放宽。

## 8. 实施顺序

修法 1+2(同函数,一个 commit) → 修法 3(观测) → 修法 4(接管 + 配置键)。
每个 commit 独立可回退;修法 3 先合有利于实测验证修法 4 的效果。
