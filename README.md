# ok-mxd

冒险岛怀旧服（进程 `Maplestory_Classic.exe` / 窗口类 `UnityWndClass` / 标题 `冒险岛怀旧服`）站桩自动打怪 MVP，基于 ok-ww 框架。

## 功能

- 定频 / 检测双模式攻击
- 自动喝血蓝
- 低血保命（回城 / 停机）
- 死亡检测（连续 20 帧空血）
- 喝药无效保护
- 画面静止 / 经验停滞兜底守卫
- YOLO 怪物检测驱动攻击（yolov8n ONNX，OpenVINO 运行时，单次检测约 22ms）

## 账号风险声明

本软件仅供个人学习 Python、计算机视觉、UI 自动化使用。使用本软件可能导致账号被封禁，后果自负。

## 使用步骤

1. 游戏设为 **2560x1440**。
2. 以**管理员身份**运行：
   ```
   H:\ok-mxd\data\apps\ok-ww\python\python.exe main_debug.py
   ```
   项目根目录为 `H:\ok-mxd\ok-mxd`。
3. 在 Start 页启动。
4. 进入触发任务页，启用「自动打怪」。

## 关键运行约束

> **必须以管理员身份运行，且游戏窗口必须保持前台。** 这是前台挂机，挂机期间不要操作键盘鼠标。

- **按键方案**：`PyDirect`（SendInput 驱动级），必须以管理员运行，且游戏窗口必须保持前台。PostMessage 后台方案已被 BlackCipher 拦截（error 5 / 静默忽略，2026-08-05 实测）。
- **只支持 2560x1440 挂机**：主循环带帧尺寸守卫，连续 10 帧不符即停。实测 UI 随分辨率缩放（2026-08-05：HP 条 200px@1440p，约 110px@1080p），其他分辨率 ROI 会偏。
- 挂机期间**不得拖动 / 缩放 / 折叠**游戏内 UI 面板，不得改分辨率。
- 按键须与游戏内设置保持一致（默认：攻击 `ctrl`、血药 `home`、蓝药 `insert`、拾取 `z`、回城卷留空）。GUI 设置页可改，改动写入 `configs/` 持久化。
- 检测模式「攻击区」默认为画面中心 60% x 60%。换站桩点后，用 `scripts/capture_frame.py` 截图量角色位置，再改任务配置里的「攻击区中心X/Y」（帧比例）。
- GUI（`main_debug.py`）启动会清空 `screenshots/` 目录（框架行为）。存档测试帧在 git 里，误删后用 `git checkout -- screenshots/test_frames/` 恢复。
- **急停**：`F9` 全局急停（已验证），或在 GUI 里停用任务。

## 兜底行为说明

- 经验 **10 分钟**不涨自动停（防无效挂机；稀缺点可在任务配置调大「经验停滞上限(分钟)」）。
- 画面静止 **60 秒**自动停。
- 药水数量 OCR 对小号数字漏检（best-effort 跳过），药没了由「连续喝药无效（5 次）」兜底停机。

## 常见问题

1. **按键无效** → 确认以管理员运行 + 游戏窗口在前台。
2. **任务开了不动** → 检查攻击键是否与游戏内一致（本项目默认 `ctrl`）。
3. **检测模式不攻击** → 确认「攻击区中心」已标定到角色站桩位置。
