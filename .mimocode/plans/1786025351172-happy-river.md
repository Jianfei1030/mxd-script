# E2E 自动化测试基建 — 实现计划

> **核心目标**：通过 UI 控制配置并启动任务 → 截图真实冒险岛客户端窗口 → 验证检测框/攻击区/怪物标记等效果。UI 控制是必要基建，游戏效果验收才是终极目标。
>
> **关键原则**：所有 UI 操作通过 OS 级输入事件模拟真实用户（鼠标移动+点击、键盘输入），
> 不是直接调用 Qt API。这确保了与用户手动操作完全等价的测试路径。

---

## 架构总览

```
外部测试脚本                          GUI 进程 (main_debug.py --e2e)
┌──────────────────────┐            ┌──────────────────────────────────┐
│ tests/               │            │ ok/gui/E2EServer.py              │
│ test_e2e_warrior.py  │──TCP JSON─→│   TCPServer (localhost:随机端口)  │
│                      │            │   ↓                              │
│ E2EClient            │←──results──│   CommandHandler                  │
│   .navigate("start") │            │     findWidget → 获取屏幕坐标    │
│   .click("button")   │            │     SetCursorPos + mouse_event   │
│   .type_text("...")  │            │     keybd_event 逐字输入         │
│   .screenshot_game() │            │     screenshot_game → base64     │
│   .screenshot_screen()│           │     screenshot_screen → base64   │
│   .get_config(...)   │            │     config read/write            │
└──────────────────────┘            └──────────────────────────────────┘
        ↓
  视觉模型验收 (截图内容验证)
```

**操作方式**：TCP localhost 进程间通信（不经过网卡），服务端收到指令后通过
`win32api.SetCursorPos` + `win32api.mouse_event` / `win32api.keybd_event`
发送真实的 OS 级输入事件，与用户手动操作完全等价。

**两种截图，两种用途**：
- `screenshot_game()` → 通过框架 WGC 抓取游戏窗口（不含 overlay），用于**数值断言**（检测到了几个怪、HP 多少）
- `screenshot_screen()` → 通过 `ImageGrab.grab` 截取屏幕区域（含 overlay），用于**视觉验收**（黄框/绿框/红框是否正确）

## 一、`ok/gui/E2EServer.py` — TCP 控制服务

在 GUI 进程内启动，绑定 `127.0.0.1:0`（随机端口），启动后向 stdout 打印 `E2E_SERVER_PORT=<port>`。

### 协议

- TCP 连接，单客户端，localhost 通信（不经过网卡）
- 每条消息 JSON + `\n` 分隔
- **控件查找**在服务端线程执行（只读 Qt widget 树）
- **控件操作**通过 OS 线程执行 `win32api` 输入事件（模拟真实用户）
- **截图**在服务端线程执行（WGC 或 ImageGrab）

### 指令集

| 指令 | 参数 | 返回 | 说明 |
|------|------|------|------|
| `ping` | — | `{ok}` | 健康检查 |
| `find` | `{name}` | `{ok, result: {exists, type, text, checked, visible, rect}}` | 查找控件状态 |
| `click` | `{name}` | `{ok}` | **OS 级点击**：定位控件屏幕坐标 → SetCursorPos → mouse_event |
| `type_text` | `{name, text}` | `{ok}` | 点击控件 → keybd_event 逐字输入 |
| `press_key` | `{key}` | `{ok}` | 按单个键（enter/escape/tab/...） |
| `hotkey` | `{keys}` | `{ok}` | 组合键（如 ["ctrl", "a"]） |
| `navigate` | `{tab}` | `{ok}` | 点击左侧导航图标 |
| `expand_card` | `{task_name}` | `{ok}` | 点击 TaskCard 展开按钮 |
| `get_config` | `{task_name, key?}` | `{ok, result}` | 读取任务配置（不涉及 UI 操作） |
| `set_config` | `{task_name, key, value}` | `{ok}` | 写入任务配置（通过 Config dict 自动持久化） |
| `start_executor` | — | `{ok}` | 点击 Start All 按钮 |
| `pause_executor` | — | `{ok}` | 点击 Pause All 按钮 |
| `screenshot_game` | `{path?}` | `{ok, result: {base64_png, w, h}}` | WGC 抓取游戏窗口（不含 overlay） |
| `screenshot_screen` | `{path?, rect?}` | `{ok, result: {base64_png, w, h}}` | 全屏截图（含 overlay），rect={x,y,w,h} 裁剪 |
| `wait_condition` | `{condition, timeout_ms, poll_ms}` | `{ok, result: {satisfied, elapsed_ms}}` | 轮询等待条件 |
| `get_status_bar_text` | — | `{ok, result: {text}}` | 读取 StartCard 状态栏文字 |

### 关键实现：OS 级点击模拟

```python
import win32api, win32con

def _os_click(self, widget):
    """模拟真实用户点击：移动鼠标 → 按下 → 抬起。"""
    # 1. 计算控件中心的屏幕坐标
    center = widget.mapToGlobal(QPoint(widget.width() // 2, widget.height() // 2))
    x, y = center.x(), center.y()
    # 2. 移动鼠标光标
    win32api.SetCursorPos((x, y))
    time.sleep(0.05)  # 模拟人类反应时间
    # 3. 发送真实的鼠标按下/抬起事件
    win32api.mouse_event(win32con.MOUSEEVENTF_LEFTDOWN, x, y, 0, 0)
    time.sleep(0.05)
    win32api.mouse_event(win32con.MOUSEEVENTF_LEFTUP, x, y, 0, 0)
```

### 关键实现：OS 级键盘输入

```python
def _os_type_text(self, widget, text):
    """先点击控件获取焦点，再逐字键入。"""
    self._os_click(widget)
    time.sleep(0.1)
    # 全选现有内容并删除
    win32api.keybd_event(win32con.VK_CONTROL, 0, 0, 0)
    win32api.keybd_event(0x41, 0, 0, 0)  # 'A'
    win32api.keybd_event(0x41, 0, win32con.KEYEVENTF_KEYUP, 0)
    win32api.keybd_event(win32con.VK_CONTROL, 0, win32con.KEYEVENTF_KEYUP, 0)
    win32api.keybd_event(win32con.VK_DELETE, 0, 0, 0)
    # 逐字输入
    for ch in text:
        win32api.VkKeyScan(ch)
        # 使用 SendInput 或 pyperclip+CtrlV
```

### 关键实现：游戏窗口截图

```python
def _screenshot_game(self):
    """通过框架 WGC 抓取游戏窗口内容（不含 overlay）。"""
    frame = og.device_manager.capture_method.get_frame()  # numpy BGR
    if frame is None:
        return None
    img = Image.fromarray(frame[:, :, ::-1])  # BGR -> RGB
    buf = io.BytesIO()
    img.save(buf, format='PNG')
    return base64.b64encode(buf.getvalue()).decode()
```

### 关键实现：全屏截图（含 overlay）

```python
def _screenshot_screen(self, rect=None):
    """截取屏幕区域（含 overlay 绘制）。"""
    # overlay 是透明窗口叠在游戏上面，ImageGrab.grab 会截到合成画面
    hwnd = og.device_manager.hwnd_window.hwnd
    if rect:
        img = ImageGrab.grab(bbox=(rect['x'], rect['y'],
                                    rect['x']+rect['w'], rect['y']+rect['h']))
    else:
        r = win32gui.GetWindowRect(hwnd)
        img = ImageGrab.grab(bbox=r)
    buf = io.BytesIO()
    img.save(buf, format='PNG')
    return base64.b64encode(buf.getvalue()).decode()
```

## 二、`ok/gui/E2ECommandHandler.py` — 控件查找 + OS 级操作

### 职责

1. **查找控件**：遍历 Qt widget 树，返回控件的屏幕坐标、类型、状态
2. **执行操作**：收到指令后，通过 `win32api` 发送 OS 级输入事件

def _discover_task_widgets(self):
    """扫描所有 TaskCard，注册 enable 开关 + 展开的配置控件。"""
    for tab in [self.mw.trigger_tab, self.mw.onetime_tab]:
        if tab is None:
            continue
        for card in tab.card_widgets:
            task_name = card.task.name
            if card.enable_button:
                self.register(f"task_{task_name}_enable", card.enable_button)
            for key, widget in card.config_widget_by_key.items():
                inner = self._extract_inner_widget(widget)
                self.register(f"task_{task_name}_{key}", inner)
```

### 操作执行（OS 级事件）

每个操作指令的处理流程：

```
click("overlay_switch")
  → widget = find("overlay_switch")          # 找到 SwitchButton 控件
  → center = widget.mapToGlobal(center)      # 计算屏幕坐标
  → win32api.SetCursorPos(center)            # 移动鼠标
  → win32api.mouse_event(DOWN + UP)          # 发送点击事件
  → time.sleep(0.1)                          # 等待 Qt 处理
  → return {ok: true}

type_text("task_战士调试_角色名", "端侧大模型")
  → widget = find("task_战士调试_角色名")     # 找到 LineEdit
  → _os_click(widget)                        # 点击获取焦点
  → Ctrl+A, Delete                           # 清空现有内容
  → pyperclip.copy("端侧大模型") + Ctrl+V    # 粘贴输入（中文需剪贴板）
  → return {ok: true}
```

**中文输入特殊处理**：`keybd_event` 无法直接输入中文字符。方案：
1. 优先用 `pyperclip` 写剪贴板 + `Ctrl+V` 粘贴
2. 备选用 `SendInput` + `KEYEVENTF_UNICODE` 标志直接发送 Unicode 字符

## 四、`tests/test_e2e_warrior.py` — WarriorDebugTask E2E 用例

### 测试类结构

```python
class TestE2EWarriorDebug(unittest.TestCase):
    """WarriorDebugTask E2E 测试。
    
    所有 UI 操作通过 OS 级输入事件模拟，与用户手动操作完全等价。
    
    前置条件：
    - 冒险岛客户端正在运行（窗口标题'冒险岛怀旧服'）
    - 角色在游戏中（非登录/选角界面）
    
    运行方式：
    1. 终端1: python main_debug.py --e2e  (输出 E2E_SERVER_PORT=xxxxx)
    2. 终端2: PYTHONPATH=. .venv-warrior/Scripts/python -m pytest tests/test_e2e_warrior.py -v --e2e-port=xxxxx
    """

    @classmethod
    def setUpClass(cls):
        cls.port = ...  # 从 --e2e-port 或环境变量读取
        cls.e2e = E2EClient(cls.port)
        cls.evidence_dir = "screenshots/e2e/warrior_debug"
        os.makedirs(cls.evidence_dir, exist_ok=True)

    def test_01_overlay_toggle(self):
        """点击 overlay 开关 → 查询状态确认已开启。"""
        self.e2e.navigate("start")
        self.e2e.click("overlay_switch")           # 真实点击开关
        result = self.e2e.find("overlay_switch")
        self.assertTrue(result["result"]["checked"])

    def test_02_warrior_config(self):
        """展开战士调试卡片 → 读写配置。"""
        self.e2e.navigate("triggers")
        self.e2e.expand_card("战士调试")
        cfg = self.e2e.get_config("战士调试")
        self.assertEqual(cfg["result"]["玩家宽"], 60)
        # 通过 Config dict 直接写入（不经过 UI 输入，因为配置测试重点是持久化）
        self.e2e.set_config("战士调试", "玩家宽", 80)
        cfg2 = self.e2e.get_config("战士调试")
        self.assertEqual(cfg2["result"]["玩家宽"], 80)
        self.e2e.set_config("战士调试", "玩家宽", 60)

    def test_03_type_character_name(self):
        """在角色名输入框中键入中文 → 查询确认。"""
        self.e2e.navigate("triggers")
        self.e2e.expand_card("战士调试")
        self.e2e.type_text("task_战士调试_角色名", "端侧大模型")
        result = self.e2e.find("task_战士调试_角色名")
        self.assertEqual(result["result"]["text"], "端侧大模型")

    def test_04_start_and_running(self):
        """点击调试开关 → 填角色名 → 点击 Start → 等待 Running。"""
        self.e2e.navigate("start")
        self.e2e.click("overlay_switch")
        self.e2e.navigate("triggers")
        self.e2e.expand_card("战士调试")
        self.e2e.click("task_战士调试_调试开关")      # 真实点击开关
        self.e2e.type_text("task_战士调试_角色名", "端侧大模型")
        self.e2e.click("task_战士调试_enable")         # 真实点击启用开关
        self.e2e.start_executor()                      # 点击 Start 按钮
        self.e2e.wait_running(timeout=5)

    def test_05_game_screenshot_has_content(self):
        """游戏窗口截图应非空且尺寸合理（WGC 抓帧验证）。"""
        img = self.e2e.screenshot_game(save_path=f"{self.evidence_dir}/game_frame.png")
        self.assertIsNotNone(img)
        self.assertGreater(img.width, 800)
        self.assertGreater(img.height, 600)

    def test_06_screen_screenshot_shows_overlay(self):
        """全屏截图应包含 overlay 绘制（视觉模型验收）。"""
        time.sleep(1)
        img = self.e2e.screenshot_screen(
            save_path=f"{self.evidence_dir}/screen_with_overlay.png"
        )
        self.assertIsNotNone(img)
        # 视觉模型验收：应有黄框/绿框/蓝框

    def test_07_full_warrior_flow(self):
        """完整流程：overlay → config → start → game截图 → screen截图 → pause。"""
        # 1. 点击开启 overlay
        self.e2e.navigate("start")
        self.e2e.click("overlay_switch")

        # 2. 配置任务（真实点击 + 键盘输入）
        self.e2e.navigate("triggers")
        self.e2e.expand_card("战士调试")
        self.e2e.click("task_战士调试_调试开关")
        self.e2e.type_text("task_战士调试_角色名", "端侧大模型")
        self.e2e.click("task_战士调试_enable")

        # 3. 点击 Start
        self.e2e.start_executor()
        self.e2e.wait_running(timeout=5)

        # 4. 等待检测稳定
        time.sleep(2)

        # 5. 游戏窗口截图（数值验证：WGC 不含 overlay）
        game_img = self.e2e.screenshot_game(
            save_path=f"{self.evidence_dir}/full_flow_game.png"
        )
        self.assertGreater(game_img.width, 800)

        # 6. 全屏截图（视觉验收：含 overlay 框线）
        screen_img = self.e2e.screenshot_screen(
            save_path=f"{self.evidence_dir}/full_flow_screen.png"
        )
        self.assertIsNotNone(screen_img)

        # 7. 验证配置持久化
        cfg = self.e2e.get_config("战士调试")
        self.assertEqual(cfg["result"]["调试开关"], True)
        self.assertEqual(cfg["result"]["角色名"], "端侧大模型")

        # 8. 点击 Pause
        self.e2e.pause_executor()

    @classmethod
    def tearDownClass(cls):
        try:
            cls.e2e.pause_executor()
        except:
            pass
        cls.e2e.close()
```

所有 UI 操作通过 OS 级输入事件模拟真实用户：
- 鼠标：`win32api.SetCursorPos` + `win32api.mouse_event(LBUTTONDOWN/UP)`
- 键盘：`pyperclip` 剪贴板粘贴（中文）或 `win32api.keybd_event`（英文/快捷键）
- 与用户手动操作完全等价，不走 Qt API 直接调用

### 12.3 架构
- **E2EServer**：GUI 进程内 TCP JSON-RPC 服务（`ok/gui/E2EServer.py`）
- **E2EClient**：外部 Python 客户端库（`scripts/_e2e_client.py`）
- 通信协议：TCP localhost（不经过网卡）+ JSON `\n` 分隔

### 12.7 编写新 E2E 用例模板
```python
class TestE2E新功能(unittest.TestCase):
    @classmethod
    def setUpClass(cls):
        cls.port = int(os.environ.get('E2E_PORT', 0))
        cls.e2e = E2EClient(cls.port)
        cls.evidence_dir = "screenshots/e2e/新功能"
        os.makedirs(cls.evidence_dir, exist_ok=True)

    def test_flow(self):
        # 1. 点击开启 overlay
        self.e2e.navigate("start")
        self.e2e.click("overlay_switch")
        # 2. 配置（真实点击 + 键盘输入）
        self.e2e.navigate("triggers")
        self.e2e.expand_card("任务名")
        self.e2e.click("task_任务名_调试开关")
        self.e2e.type_text("task_任务名_角色名", "角色名")
        # 3. 启动
        self.e2e.click("task_任务名_enable")
        self.e2e.start_executor()
        self.e2e.wait_running(timeout=5)
        # 4. 截图验证
        time.sleep(2)
        game_img = self.e2e.screenshot_game(f"{self.evidence_dir}/game.png")
        screen_img = self.e2e.screenshot_screen(f"{self.evidence_dir}/screen.png")
        # 5. 断言
        self.assertIsNotNone(game_img)
        # 6. 清理
        self.e2e.pause_executor()
```

## 十、风险与对策

| 风险 | 对策 |
|------|------|
| 鼠标移动干扰用户操作 | E2E 测试时用户不应操作电脑；鼠标会自动移到控件位置 |
| 控件被遮挡（窗口重叠） | 点击前检查控件 visible 状态；必要时先 bring_to_front |
| 中文输入 keybd_event 不支持 | 用 pyperclip 剪贴板粘贴方案；备选 SendInput UNICODE |
| WGC 抓帧需要游戏窗口存在 | `screenshot_game` 失败时返回明确错误，测试 skip |
| 全屏截图时 overlay 未绘制 | 截图前 sleep 等待至少一个检测周期（0.3~1s） |
| 控件查找失败（TaskCard 未展开） | `expand_card` 先展开再查找；CommandHandler 启动时动态扫描 |
| TCP 消息粘包 | 行缓冲（`\n` 分隔），客户端/服务端都做 |
| E2E 服务端口未知 | stdout 打印 `E2E_SERVER_PORT=`，客户端从环境变量/参数读取 |
| 焦点切换导致输入错位 | type_text 先 click 获取焦点再输入；加 sleep 等待焦点稳定 |
